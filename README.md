Practical 8: Image Colorization
Aim

To perform image colorization on a grayscale image using Python and OpenCV.

Introduction

Image colorization is the process of assigning colors to a grayscale image. In this practical, OpenCV is used to apply a color map to different intensity levels of a grayscale image.

Technologies Used
Python
OpenCV
NumPy
How It Works
Read the grayscale image.
Convert/read the image in grayscale format.
Apply an OpenCV color map.
Display the original grayscale image.
Display the colorized image.
Save the colorized image.
